# حلو | Helw — موقع عقاري

موقع عقاري عربي (RTL) لشركة **حلو العقارية** — بيع وشراء وإيجار وإدارة العقارات في مصر.

مبني بـ **Next.js 14** (App Router) وخط **Tajawal**، وجاهز للنشر على Vercel بدون أي إعدادات إضافية.

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:3000
```

## البناء والإنتاج

```bash
npm run build
npm start
```

## أماكن مهمة لتعديلها

| ماذا تريد أن تغيّر | الملف |
| --- | --- |
| رقم الواتساب والتليفون | `app/SearchHome.jsx` و `app/ContactForm.jsx` و `app/page.jsx` (ابحث عن `WHATSAPP` / `201001234567` / `+201001234567`) |
| الوحدات العقارية المعروضة | مصفوفة `PROPERTIES` في `app/SearchHome.jsx` |
| أرقام الإحصائيات والخدمات وآراء العملاء | `app/page.jsx` |
| الألوان والهوية | متغيرات CSS في أول ملف `app/globals.css` |
| صور الوحدات | مجلد `public/props/` و `public/hero.jpg` |

> ملاحظة: الرقم `+20 100 123 4567` رقم مؤقت للتوضيح — استبدله برقمك الفعلي قبل الإطلاق.

## النشر على Vercel

الريبو مربوط بالفعل بمشروع Vercel على <https://helw.vercel.app> — أي دمج (merge) في فرع `main` بيرفع النسخة الجديدة تلقائياً.
